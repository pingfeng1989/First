# First

基于 Python 的汽车 HUD 简单仿真工具

这个项目的目标是开发一个用于汽车 HUD 的基础仿真工具，使用 Python 实现 HUD 元素和显示逻辑。当前主要功能是通过输入 `VID` 和 `FOV`，展示驾驶员可以看到的视野尺寸和路面覆盖情况。项目将重点展示：

- 简单的 HUD 界面布局
- 车速、燃油、方向、档位等信息显示
- VID/FOV 输入后视野宽高计算
- 路面覆盖情况估算（可视车道数）
- 模拟动态数据更新和交互
- 适合汽车 HUD 视野仿真练习

## 项目说明

我希望通过这个仓库记录汽车 HUD 仿真工具的开发过程，逐步完善功能和演示效果。当前示例支持：

- 显示当前 `VID`（可视化距离）
- 显示当前 `FOV`（水平视场角）
- 计算并显示视野宽高
- 估算当前可视路面车道数
- 支持键盘交互调整 `VID` 和 `FOV`

后续会补充具体实现、演示截图和使用说明。欢迎关注与反馈。

## 示例实现

项目已包含一个简单的 Python HUD 仿真示例脚本：`hud_sim.py`

使用方式：

```bash
python hud_sim.py
```

该示例展示了速度、航向、高度、姿态指示和动态更新效果，适合作为后续 HUD 开发的起点。
